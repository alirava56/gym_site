# چک‌لیست سختگیرانه انتشار (Editorial + SEO + Engineering)

## P0 — تا این‌ها انجام نشده، Publish نکنید

- [ ] مالک سایت، نام برند «شب قهرمانان» را در خروجی نهایی تأیید کرده باشد.
- [ ] مربی واجد صلاحیت حرکات/جدول و متخصص تغذیه یا فرد ذی‌صلاح ادعاهای تغذیه‌ای را بازبینی کند؛ نام، سمت و سابقه واقعی فقط با اجازه درج شود.
- [ ] دامنه HTTPS واقعی و مسیرهای `/blog` و دو اسلاگ مقاله موجود باشند؛ هر دو صفحه HTTP 200 بدهند.
- [ ] عکس‌های واقعی یا دارای مجوز قانونی تهیه و متن جایگزین (alt) بررسی شوند.
- [ ] CTA به رزرو/مشاوره واقعی برسد، نه صرفاً یک دکمه بدون عملکرد؛ فعلاً لینک به صفحه اصلی است.
- [ ] هیچ تاریخ جعلی، بازبین ساختگی، ادعای «نتیجه تضمینی»، تست غیرواقعی یا قبل/بعد ساختگی درج نشود.
- [ ] منابع علمی قابل دسترسی و مرتبط باشند، و پیوند منابع در UI دیده شود.

## P1 — On-page و فنی

- [ ] برای هر صفحه دقیقاً یک H1 و H2/H3 منطقی؛ جدول‌ها accessible و روی موبایل اسکرول‌پذیر.
- [ ] عنوان `<title>`، متادیسکریپشن، canonical، Open Graph، Twitter card یکتا.
- [ ] لینک داخلی دوطرفه مقاله‌ها + لینک از فهرست بلاگ و صفحه خانه + مسیر رزرو.
- [ ] JSON-LD `BlogPosting` و `BreadcrumbList` با تاریخ انتشار واقعی و URL/تصویر واقعی در Rich Results Test بررسی شود.
- [ ] عکس‌ها WebP بهینه، ابعاد مشخص، OG 1200×630؛ برای عکس بالای صفحه lazy-load نشود.
- [ ] HTML اولیه حاوی متن؛ metadata به سمت Client Component منتقل نشود.
- [ ] `robots.txt`، sitemap، noindex، canonical و redirectها کنترل شوند.
- [ ] کیفیت فونت فارسی، نیم‌فاصله، متون RTL و اعداد، کیبورد و لمس موبایل تایید شود.

## P2 — برنامه پس از انتشار

- [ ] URL Inspection و ثبت sitemap در Google Search Console.
- [ ] خط مبنا در Google Analytics/Search Console ثبت شود؛ داده حجم/سختی کلمه بدون ابزار معتبر ادعا نشود.
- [ ] رویداد CTA و نرخ تبدیل واقعی (شروع رزرو، رزرو تکمیل‌شده) ثبت شود؛ بدون ذخیره داده‌های حساس در پارامتر analytics.
- [ ] در روزهای ۲۸، ۵۶ و ۹۰ موضوع کوئری‌ها، CTR و محتوا بر اساس داده بررسی شود؛ تاریخ صفحه فقط با تغییر واقعی به‌روز شود.
- [ ] در صورت داشتن عکس/ویدیو واقعی مربی، یک قطعه آموزشی بومی به هر مطلب اضافه شود تا ارزش تجربه دست‌اول تقویت شود.

## بازه‌های کلیدواژه بدون ادعای رتبه

- مقاله اول: intent «برنامه سه روزه تازه‌کار»، نه «چربی‌سوزی سریع».
- مقاله دوم: intent «کاهش چربی + حفظ عضله»، نه «برنامه بدنسازی مبتدیان».
- عبارت‌ها و تگ‌های جداشده با کاما فقط برای سامان‌دهی محتوا و پایش جست‌وجو هستند، نه فیلد جادویی رتبه‌بندی.
